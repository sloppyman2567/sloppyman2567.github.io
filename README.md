# sloppyman2567.github.io

The host root of [sloppyman2567.github.io](https://sloppyman2567.github.io/). It exists so search engines have a home page for
this host to read the site name ("bifrost-emu") and the icon from: Google supports both only at the domain or subdomain
level, and the project page lives under `/bifrost-emu/`, which is generated from
[bifrost-emu](https://github.com/sloppyman2567/bifrost-emu) (`Tools/Site/`). The icon is `Assets/Branding/bifrost-emu-icon.svg`
there, rendered to the PNG and ICO files here (`rsvg-convert -w 48 icon.svg`; `favicon.ico` holds 48, 32 and 16 px).
